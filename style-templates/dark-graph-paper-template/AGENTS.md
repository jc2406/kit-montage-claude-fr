# Instructions du template

Suivez le guide racine de l'espace de travail et le DESIGN.md de ce template. Copiez ce template
dans un projet vidéo avant de le modifier. Lisez style-templates/README.md à la racine pour les assets requis.
Utilisez les skills HyperFrames de la racine. Lancez le lint, l'aperçu et inspectez les images rendues après
toute modification d'une composition. Toute publication nécessite l'autorisation de l'utilisateur.
