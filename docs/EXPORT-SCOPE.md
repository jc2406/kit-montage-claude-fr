# Périmètre de l'export

La partie « pipeline » a été assemblée à l'origine à partir d'une liste autorisée de skills
réutilisables, de scripts, de sources de la bibliothèque et de sources de modèles, avec un
historique public neuf. Le dépôt d'origine a fusionné cet historique dans le kit étudiant public ;
il n'importe pas l'historique Git de l'espace de production privé.

Le skill de format court contient ses instructions, une fiche de référence généralisée et ses
validateurs. Les noms de fichiers des vidéos de référence personnelles et l'analyse de
l'enregistrement privé ont été remplacés par une fiche réutilisable. Les données de test
synthétiques ont été écrites séparément. Aucun enregistrement privé, aucune transcription, aucune
décision de montage, aucun identifiant ni réglage propre à une machine n'a été ajouté.

## Version française

Cette traduction ne reprend pas les médias du dépôt d'origine :

- les 12 projets pédagogiques de `video-projects/` ;
- les éléments de marque AI Automation Society (`assets/`, `DESIGN.ais-example.md`) ;
- les vidéos de démonstration de `examples/showcase/` et leurs images d'aperçu.

Ces médias montrent Nate Herk ou la marque AI Automation Society, et la licence ne donne aucun
droit sur une image, une marque ou un média exclu. Ils restent disponibles dans le
[dépôt d'origine](https://github.com/nateherkai/herk-edit-kit). Le vérificateur `npm run check`
refuse tout fichier vidéo ou audio dans la distribution.

Les nouveaux médias et projets des utilisateurs sont ignorés par Git.
